# 📚 Study Tracker

A modern, responsive study-tracking web application built with HTML, CSS, and JavaScript.

Study Tracker helps students record study sessions, set goals, track streaks, analyze their progress, plan upcoming sessions,set stopwatch to increase their speed, and stay consistent with their studies.

## ✨ Features :-

  ### 📊 Dashboard
  
  * Today's study time
  * Total study time
  * Total sessions
  * Study streak
  * Daily study goal
  * Weekly study goal
  
  ### 📝 Study Sessions
  
  * Add study sessions
  * Record subject, topic, duration, date, and notes
  * Edit existing sessions
  * Delete sessions
  * Automatically save data using browser local storage
  
  ### 📈 Analytics
  
  * Subject-wise study distribution
  * Weekly study chart
  * Average session length
  * Best-performing subject
  * Best study day
  * Goal completion
  * Study activity calendar
  
  ### ⏱️ Study Timer
  
  * Pomodoro mode
  * Focus mode
  * Deep Work mode
  * Custom timer
  * Start, pause, and reset controls
  * Completed timer sessions can be added to study history
  
  ### 🧠 Learning Tools
  
  * Flashcards
  * Flashcard review mode
  * Revision checklist
  * Study planner
  * Planned-session reminders
  
  ### 🏆 Gamification
  
  * XP system
  * Levels
  * XP progress bar
  * Achievement badges
  * Study streak tracking
  * Confetti rewards
  
  ### 💾 Data Management
  
  * Local browser storage
  * Export study data as CSV
  * Backup data as JSON
  * Restore data from JSON
  * Clear stored study data
  
  ### 🎨 User Experience
  
  * Dark mode
  * Light mode
  * Responsive mobile layout
  * Daily study quotes
  * Toast notifications
  * Interactive wizard cursor
  * Study Buddy assistant
  
  ### 📱 Progressive Web App
  
  Study Tracker includes PWA support so it can be installed as a standalone application.
  
  * PWA manifest
  * App icons
  * Service worker
  * Standalone app experience
  * Offline caching for core project files

## 🛠️ Built With
